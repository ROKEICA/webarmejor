# WebAR Pipas Mega - Experiencia Web de Producción
Generado el: 27/11/2026, 12:37:12 p. m.

Paquete web listo para publicar en cualquier hosting con HTTPS (Cloudflare Pages/Workers, Netlify, Vercel, cPanel, GitHub Pages).

## Cómo publicar
1. Sube el contenido de este ZIP a la raíz del hosting (o el ZIP completo en Cloudflare).
2. El sitio debe abrirse con **HTTPS** (requisito del navegador para usar la cámara del celular).
3. Abre la URL en el celular y apunta la cámara a cualquiera de los 4 empaques Pipas Mega.

## Contenido
- `index.html`, `css/`, `js/`: aplicación de Realidad Aumentada (incluye three.js y MindAR en `js/vendor/`).
- `data/project.json` y `config/project.json`: contenido del editor (28 elementos 3D, 0 botones de pantalla). También va incrustado en index.html.
- `targets/`: marcadores `targets.mind` y carátulas de los empaques.
- `assets/`: modelos, imágenes, GIF, fuentes y archivos subidos desde el editor.
- `.htaccess`, `_headers`, `vercel.json`, `web.config`: tipos MIME y cabeceras para cada servidor.
